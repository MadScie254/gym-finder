# Decisions

One line each: what, why, evidence. Do not re-litigate the brief.

- 2026-10-11 — Product name is **Find My Gym**, not KAYA. Owner chose the brief palette (`#C82F0B`) and a new name. Trust copy: “Verified by Find My Gym” only from an override file.
- 2026-10-11 — Data-in-Git for published files (`public/data/gyms.<hash>.json`, `manifest.json`, `landmarks.json`). Raw snapshots stay in gitignored `data/source/`. Monthly Action opens a PR that updates published files. Why: SPA must run without DuckDB on a contributor machine.
- 2026-10-11 — Abandon in-app OSRM (`app/api/map/route`, RoutePanel) at cutover. Brief F-13 is Google Maps URL + `geo:`; F-20 is straight-line geometry. In-app routing needs a server.
- 2026-10-11 — DuckDB via `@duckdb/node-api` on CI (Node 24). Local Node 26 / Windows is missing `@duckdb/node-bindings-win32-x64`; extract-overture.mjs uses a DuckDB CLI in `tools/` if present. Do not commit the CLI. Python is not installed on this machine.
- 2026-10-11 — Overture extract could not be run in this session (no DuckDB CLI, no Python, Node bindings fail). OSM extract + merge still run. D1 is not claimed until Overture lands.
- 2026-10-11 — Golden-set CI uses the brief seed (present in source data). Web-researched names are candidates only if they appear in the built catalog. Never ingest listicle prices/hours/ratings. Catalog remains Overture ∪ OSM ∪ overrides.
- 2026-10-11 — Pin after `npm view` (2026-10-11): Vite 8.3.4, `@vitejs/plugin-react` 6.1.2, React 19.2.8, React Router 7.18.4 (7.x as specified; 8.4.0 also current), Zustand 5.0.15, MiniSearch 7.2.0, Zod 4.6.6, libphonenumber-js 1.13.15, `@duckdb/node-api` 1.5.6-r.1, lucide-react 1.55.0, vaul 1.1.2, vite-plugin-pwa 2.0.0, `@fontsource-variable/inter` 5.3.0, opening_hours 3.15.0 (still maintained).
- 2026-10-11 — `@` alias: Vite maps `@` → `src/`; `@data` → `data/`. Next keeps root `@/` until cutover.
- 2026-10-11 — UI state uses React context, not Zustand, for this slice. Native `<details>` stands in for a Radix popover on the trust badge. Service worker is hand-written (`public/sw.js`) rather than vite-plugin-pwa. Hours use a documented subset (24/7 and weekday ranges); other strings are shown raw.
- 2026-11-11 — Golden list (D7): 40 venues = every eligible non-Nairobi venue (corroborated, phone, own non-social site; Physiq & Tone dropped, its "site" is YouTube) plus 14 Nairobi. Nairobi kept well under the cap of 22 so all 14 counties with an eligible venue are covered.
- 2026-11-11 — A website check verifies a venue only when the site shows current operation (current-year copyright, content dated in the last 12 months, or a current dated notice). Sites that are up but undated or old (Ongata Rongai Boxing Club, K-Fitness, Hyat, Colosseum) get no badge. Evidence: `data/research/site-checks-2026-11-11.json`.
- 2026-11-11 — Prices only when currency and period are in the same statement (Dojo's currency-less rate table is skipped). `asOf` = date read on a page with current content, `null` if the page is undated. A steam room is not a sauna. Days a full weekly schedule leaves out are treated as closed in OSM hours (Tumaini Sunday); hours without days stay text only.
- 2026-11-11 — Website-verified venues show "Details confirmed on the gym's own website on <date>" with trust score 90; 95 stays for phone or visit checks. Overrides are now Zod-validated in `scripts/data/overrides.mjs`; the build fails on a field without a URL and quote.
- 2026-11-11 — `data/source/` was missing, so it was re-extracted: Overture pinned to 2026-10-21.0 (run with AWS env credentials unset, since the injected ones broke anonymous S3); every Overpass mirror failed, so the existing 2026-09-17 OSM snapshot was reused. The rebuild reproduces the committed 566 records exactly (only row order differs).
- 2026-11-11 — Fahari Gym and Sports is not excluded although its site is an equipment shop at the same address: the site does not show that no gym runs there, and it is a golden seed name. No venue was marked closed: a dead domain is not evidence of closure.
- 2026-11-11 — MapLibre is the only map. Removed `GoogleMapPane`, both `@googlemaps/*` packages, `@types/google.maps` and the `VITE_GOOGLE_*` switch: no owner decision kept Google and `AGENTS.md` forbids runtime API keys. Directions stay a plain Google Maps link (no key).
- 2026-11-11 — Playwright pinned to 1.63.0, with an npm `overrides` entry pinning `playwright-core` to 1.63.0 (`@axe-core/playwright` otherwise pulls 1.65). Why: the machine ships Chromium build 1243 under `PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`; 1.63 is the release that expects 1243. `chromium-1194` named in the brief does not exist here. `PW_CHROMIUM_PATH` overrides the binary.
- 2026-11-11 — The e2e build is `vite build --mode e2e` (still a production build). `/styleguide` is mounted only when `MODE !== "production"`, so dev and e2e have it and the shipped bundle drops the chunk (checked: no Styleguide asset in `dist` after `npm run build`).
- 2026-11-11 — Font: Archivo from `@fontsource-variable/archivo` 5.3.0, which does ship the width axis (62–125). Its latin file is 90 KB, over the 60 KB budget, so `scripts/instance-font.mjs` limits it to wdth 75–100 and wght 400–800 with fontTools: one 57,776-byte woff2 committed in `src/ui/fonts/`. Fontsource stays a devDependency as the source. OFL 1.1, no reserved font name.
- 2026-11-11 — Bottom sheet is hand-rolled (`src/ui/Sheet.tsx`), not `vaul`, although vaul 1.1.2 accepts React 19. Why: vaul is a Dialog replacement (its README), the Explore sheet is a persistent non-modal region; vaul hard-codes a 0.5 s inline transition against the plan's 160–200 ms; its handle is not focusable; snap points are measured against the window, not the map area.
- 2026-11-11 — Tailwind removed (it styled one error screen). One styling system: tokens in `src/ui/tokens.css` plus a CSS module per component. Legacy `src/styles.css` keeps running, its colours aliased to the tokens, until Phase 4 replaces those screens.
- 2026-11-11 — Contrast fixes after measuring the plan palette: court `#0C8558` → `#0A7A51` and stop `#D23A2A` → `#C43420` (both were under 4.5:1 on chalk); dark-mode distance block is `#0D1220` with a `#7D889D` edge because plate-on-plate measured 1.38:1. `npm run check` now runs `scripts/contrast.mjs`. Table in `docs/DESIGN_SYSTEM.md`.
- 2026-11-11 — `--color-line` (plate 10%) stays decorative for card hairlines and is not held to 3:1; every control edge uses `--color-line-strong` (3.08:1 minimum). Buttons and fields take a 6 px radius, a fourth role the plan's three radii did not cover.
- 2026-11-11 — Search fuzziness is per term: 0 edits up to 3 letters, 1 up to 5, 2 from 6. A transposition costs 2 edits, so the old flat `fuzzy: 0.2` could not match "slaute" to "salute" and the first result for "slaute gym" was an unrelated gym. Golden test pins Salute Gym first.
- 2026-11-14 — Adopt the owner-supplied product proposal of 2026-11-12 where it does not undo an owner request. Primary navigation becomes Home, Find gyms, Saved, My week. `/` is a real homepage; discovery lives at `/search` and `/in/:place`. Back from a gym restores query, filters, map position and list scroll. Map panning offers "Search this area" instead of silently re-filtering. Lists show an explicit range with Load more. Commute and the generic More page leave the main experience. Meals and the shopping checklist move into My week. The owner asked for a food simulation on 2026-11-11, so the demo stores stay, reached from My week as a clearly marked demo section, not as a primary tab.
