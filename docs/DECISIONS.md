# Decisions

One line each: what, why, evidence. Do not re-litigate the brief.

- 2026-10-11 — Product name is **Find My Gym**, not KAYA. Owner chose the brief palette (`#C82F0B`) and a new name. Trust copy: “Verified by Find My Gym” only from an override file.
- 2026-10-11 — Data-in-Git for published files (`public/data/gyms.<hash>.json`, `manifest.json`, `landmarks.json`). Raw snapshots stay in gitignored `data/source/`. Monthly Action opens a PR that updates published files. Why: SPA must run without DuckDB on a contributor machine.
- 2026-10-11 — Abandon in-app OSRM (`app/api/map/route`, RoutePanel) at cutover. Brief F-13 is Google Maps URL + `geo:`; F-20 is straight-line geometry. In-app routing needs a server.
- 2026-10-11 — DuckDB via `@duckdb/node-api` on CI (Node 24). Local Node 26 / Windows is missing `@duckdb/node-bindings-win32-x64`; extract-overture.mjs uses a DuckDB CLI in `tools/` if present. Do not commit the CLI. Python is not installed on this machine.
- 2026-10-11 — Overture extract could not be run in this session (no DuckDB CLI, no Python, Node bindings fail). OSM extract + merge still run. D1 is not claimed until Overture lands.
- 2026-10-11 — Golden-set CI uses the brief seed (present in source data). Web-researched names are candidates only if they appear in the built catalog. Never ingest listicle prices/hours/ratings. Catalog remains Overture ∪ OSM ∪ overrides.
- 2026-10-11 — Pin after `npm view` (2026-10-11): Vite 8.3.4, `@vitejs/plugin-react` 6.1.2, React 19.2.8, React Router 7.18.4 (7.x as specified; 8.4.0 also current), Zustand 5.0.15, MiniSearch 7.2.0, Zod 4.6.6, libphonenumber-js 1.13.15, `@duckdb/node-api` 1.5.6-r.1, lucide-react 1.55.0, vaul 1.1.2, vite-plugin-pwa 2.0.0, `@fontsource-variable/inter` 5.3.0, opening_hours 3.15.0 (still maintained).
- 2026-10-11 — `@` alias: Vite maps `@` → `src/`; `@data` → `data/`. Next keeps root `@/` until cutover.
- 2026-10-11 — UI state uses React context, not Zustand, for this slice. Native `<details>` stands in for a Radix popover on the trust badge. Service worker is hand-written (`public/sw.js`) rather than vite-plugin-pwa. Hours use a documented subset (24/7 and weekday ranges); other strings are shown raw.
- 2026-10-13 — Merge rules (a)/(b) are distance-gated: a shared phone or own-domain site merges on its own within 150 m, within 2 km only with name Jaccard >= 0.5, beyond that it goes to review as `shared-contact-distant`. Why: chains share numbers and sites (measured: "Smart Gyms" pair 21 km apart, Zoezi 267 km). Rule (c) and "never on proximity alone" are unchanged.
- 2026-10-13 — Web research joins at most one existing venue (seed id > phone/website > name, then name similarity); a tie leaves the finding out and logs it as ambiguous, so one finding can never fuse two venues or close both. Union-find alone allowed a town-radius (8 km) web record to bridge two branches.
- 2026-10-13 — Web research is a fourth source (supersedes "catalog remains Overture ∪ OSM ∪ overrides" of 2026-10-11; still no listicle prices or ratings). Web findings have no coordinates: placed at their suburb (2 km) or town (8 km) centre from kenya-places.json, flagged approximate in provenance and reasons; web-only is Listed at most. Hedged statuses ("operating (unverified)", "likely", "?") count as uncertain and are never imported.
- 2026-10-13 — Town is derived after the county: "Nairobi" for all of Nairobi City County, else the nearest town within 30 km not named after another county. Nearest-GeoNames-town labelled 142 venues wrongly (Karen as Ngong, Kasarani as Ruiru, Utawala as Githunguri).
- 2026-10-13 — County: source county hint (Overture locality/region, OSM addr:county) wins within 75 km slack of the nearest centroid; un-hinted OSM takes a hinted neighbour's county within 1.5 km. Known limit: ~5 venues around Ruaka may be Kiambu, not Nairobi; county polygons would fix it.
- 2026-10-13 — Overture `sports_and_recreation` and a missing taxonomy are name-gated like `sport_or_fitness_facility` (Meta files many real gyms there). The brief's "or matches an OSM gym" admission is not implemented: the extract only fetches those categories when the name matches, so it could never fire (the only candidate measured is a sporting-goods store next to Fahari Gym).
- 2026-10-13 — Soft deny: a name with no fitness word that names a hotel, hall, stadium, school and so on is kept but Unconfirmed (hidden from browse, found by exact name), logged in denylist-hits.json (12 records).
- 2026-10-13 — Override review: allow "Classic Gym and Executive Salon" (deny-list false positive, Meta category sports_and_recreation); exclude "Karen Blixen Camp, Masai Mara" (safari camp) and "The Gym Shop" (retail stall). Samnick Enterprises and Ultra Smart Controls stay as the brief's human-review pairs.
- 2026-10-13 — Search fuzziness by term length: 0 edits for 1-2 letters, 1 for 3-5, 2 for 6+ (an adjacent swap costs 2). Exact and prefix hits still rank first.
- 2026-10-13 — Validation: the published Venue schema is strict (an unknown key such as `rating` fails), websites need a real top-level domain, and both total and default-visible may not drop more than 15% below the previous build.
